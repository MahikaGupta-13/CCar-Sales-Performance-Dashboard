Car Sales Analytics Dashboard
Car Sales Analytics Dashboard is a business intelligence solution providing interactive insights into car sales performance by model, region, and profitability—supporting strategic decisions through dynamic Power BI dashboards.

🌟 Features
Sales performance analysis by brand, model, and region
Interactive Power BI dashboards with drill-down capabilities
Dynamic filtering by category, year, and profitability
Visual KPIs (Units Sold, Revenue, Margins)
Intuitive, executive-friendly reporting interface

📂 Modules
Dashboard: Power BI visualizations, slicers, KPIs
Sales Analysis: Insights by model, brand, and geography
Data Model: Cleaned and structured car sales data

🛠 Technologies Used
Power BI
MS Excel
Data Modeling & Cleaning
